About

The person behind
the code

I'm Kizar, a builder from Algiers, Algeria. I don't call myself a "full-stack developer" because that title gets thrown around too loosely. I'm the person who actually makes the whole thing work — from the native Android plugin that downloads files, to the API layer that handles rate limits, to the frontend that shows it all.

My philosophy: "If it takes more than two clicks, it should be automated." Every app I make is about removing friction.

I work alone. That means I'm the frontend dev, the backend dev, the API integrator, the DevOps person, the QA tester, and the person who fixes the bug at 3am. 48 releases in about two months.

I don't use AI to write my code. I use it to research, to understand APIs, to debug faster. The architecture, error handling, retry logic, caching strategies — that's all me figuring it out by reading docs, breaking things, and putting them back together better.
