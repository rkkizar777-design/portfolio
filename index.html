About me

I'm Kizar, a builder from Algiers, Algeria. I don't call myself a "full-stack developer" because that title gets thrown around too loosely. I'm the person who actually makes the whole thing work — from the native Android plugin that downloads files, to the API layer that handles rate limits, to the frontend that shows it all.

My philosophy: "If it takes more than two clicks, it should be automated." That's not just a bio — it's how I actually build. Every app I make is about removing friction.

I work alone on my projects. That means I'm the frontend dev, the backend dev, the API integrator, the DevOps person, the QA tester, and the person who fixes the bug at 3am. I've shipped 44 releases of my main project in about two months.

I don't use AI to write my code. I use it to research, to understand APIs, to debug faster. The actual architecture, the error handling, the retry logic, the caching strategies — that's all me figuring it out by reading docs, breaking things, and putting them back together better.

What I actually do

Not a buzzword list. These are things I've built with, broken, and fixed.

📱

Android / Capacitor

Native Android plugins in Java. Download managers, file providers, install intents. Not just wrapping a webview — I write the native bridges when Capacitor isn't enough.

⚡

API Integration

GitHub API, rate limiting, proxy handling, retry logic with exponential backoff. Fetch layers that survive 503 errors, token expiry, and network failures gracefully.

🚀

Frontend / React

Complex state management, 9500+ line single files, real-time updates, intersection observers, scroll-driven animations. Not pretty — functional.

📦

Caching & Offline

In-memory caches, persistent localStorage with versioning, stale-while-revalidate patterns, 24-hour persistent cache. Your data loads instantly.

💬

Real-time Features

P2P messaging, chat systems, polling mechanisms. Built a full messaging system without a server.

🛡

Error Handling

Retry logic, fallback chains, graceful degradation. If one method fails, two more are waiting. I don't let apps crash.

💻

Backend / APIs

REST API design, GitHub proxy servers, OAuth flows, token management. Build backends that don't need to exist.

🏆

Deployment

GitHub Releases, Vercel, Gradle builds, Android signing. From code to APK in your hands. Automated pipelines that work.
